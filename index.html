Recent updates, fixes, and engine improvements.

v1.12.11 — Semantic Speech Camera & Subtitle AI Polish

2026-08-31
  • ✓ Mouse Activity Veto: Pointer movements and clicks strictly prevent full-screen webcam takeover, keeping the demonstration view in focus.
  • ✓ Speech Semantics: Demonstration phrases ("click here", "open settings") keep camera in PiP inset, while conceptual talks and intros expand to full frame.
  • ✓ Mandatory Pre-Assembly Transcription: Speech is always transcribed before layout decisions to avoid overlays on silence.
  • ✓ AI & Deterministic Subtitle Cleanup: Automated repetition loop pruning, stutter collapse, and LLM text polishing with hero-word emphasis sync.

v1.12.10 — Camera Mirroring, Bounds & A/V Sync

2026-08-31
  • ✓ Webcam Horizontal Mirroring: selfie-mode mirroring by default in preview, recording, and live stream with toggle switch.
  • ✓ Screen Boundary Preservation: auto-zoom clamped strictly within footage bounds, keeping edge text/tabs completely visible on laptops.
  • ✓ Windows Voiceover Sync: normalized PTS timestamps and CFR encoding eliminating startup audio drift.
  • ✓ AudioContext Auto-Resume: unblocked Web Audio initialization without input delay.

v1.12.9 — Cross-Platform Package Manager & 1-Click Auto Install

2026-08-31
  • ✓ In-App Packages & Models Manager with 1-click automatic downloading of FFmpeg, FFprobe, and Whisper models.
