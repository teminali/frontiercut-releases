FrontierCut Release Hosting & Distribution

FrontierCut uses a decoupled, two-tier architecture to deliver instant, secure, and authenticated desktop releases while keeping proprietary core engine source private.

1. Architecture Diagram

┌───────────────────────────────┐
│ Private Core Repository       │  (Full engine source code)

└───────────────┬───────────────┘
                │ git push tag vX.Y.Z
                ▼
┌───────────────────────────────┐
│ GitHub Actions Release Matrix │  (macOS ARM64/x64, Windows x64, Linux)
└───────────────┬───────────────┘

                ▼

3. Auto-Updater Feeds & Cryptographic Checksums

Each release publishes metadata manifests containing SHA-512 cryptographic hashes alongside the application binaries:

  • latest-mac.yml: macOS feed containing ARM64 and x64 DMG and ZIP package hashes.
  • latest.yml: Windows feed containing NSIS installer hashes.
  • latest-linux.yml: Linux AppImage manifest.

4. Verifying Download Integrity

To verify the SHA-512 checksum of any downloaded file in the terminal:

# macOS / Linux
shasum -a 512 <downloaded-file>

# Windows PowerShell
Get-FileHash -Algorithm SHA512 .\<downloaded-file>
