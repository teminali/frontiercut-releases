# FrontierCut v1.12.7

## Classic Clean Captions & In-App FrontierCut Branding

FrontierCut **v1.12.7** streamlines the Tutorial Skill to default to classic, high-legibility subtitle typography and completes the in-app branding transition with the new FrontierCut "F" precision-cut logo mark.

### Key Highlights
- **Classic Subtitles Default**: The Tutorial Skill now builds clean, classic subtitle captions on `T1 · Subtitles` by default, removing oversized bouncing kinetic typography for a professional, clean viewing experience.
- **Official In-App FrontierCut Branding**: Updated the header bar, home navigation, project defaults, system prompts, error boundaries, and SVG favicons with the new FrontierCut "F" logo.
- **Enhanced Speech Alignment**: Preserves word timestamp synchronization, automatic sentence line balancing, and spell checking before placement on the timeline.
- **Universal Multi-Platform Builds**: macOS (Apple Silicon & Intel), Windows 64-bit (Setup EXE), and Linux (AppImage) packages available.
